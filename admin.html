ऑर्डर

ऑर्डर सूची के लिए मौजूदा वेबसाइट backend से अलग API कनेक्शन चाहिए।

इस एडमिन build में केवल Cloudflare catalog API जोड़ी गई है। ऑर्डर डेटा का API अभी पुष्टि नहीं हुआ, इसलिए यहाँ काल्पनिक ऑर्डर नहीं दिखाए जा रहे हैं।

बैनर / पोस्टर

बैनर / पोस्टर मैनेजमेंट को जोड़ने के लिए उसकी मौजूदा storage/API जानकारी चाहिए। अभी इस पेज पर कोई अलग backend action नहीं चलाया जा रहा है।

ग्राहक पूछताछ / फीडबैक

ग्राहक फीडबैक को इस build में बिना उसके database/API की पुष्टि के नहीं बदला गया है।
